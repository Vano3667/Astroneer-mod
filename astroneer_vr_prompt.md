# Astroneer VR-мод для Meta Quest 3 (Standalone) — промт для AI-агента

## Исходные данные

- **Игра**: Astroneer (Steam-версия, Unreal Engine 4)
- **Цель**: Standalone VR-мод для Meta Quest 3 (нативный Android-билд, без PCVR)
- **Уровень разработчика**: Начинающий (базовое программирование, без опыта в UE/gamedev)
- **Стратегия**: Начать с прототипа через UEVR, затем углубляться в нативный порт
- **Платформа**: Quest 3 (Qualcomm Snapdragon XR2 Gen 2, Android, ARM64)

## Важное предупреждение агенту

Этот проект **экстремально сложен** для начинающего разработчика. Standalone-порт AAA-игры под Android требует:
- Глубокого знания Unreal Engine 4 (рендер-пайплайн, система сборки, платформенные абстракции)
- Опыта кросс-компиляции C++ под ARM64/Android
- Понимания мобильного рендеринга (Adreno GPU, тайловый рендер, Vulkan/OpenGL ES)
- Знания Oculus Mobile SDK / OpenXR runtime

Твоя задача как агента — **максимально упрощать**, объяснять каждый шаг, давать готовые команды и не предполагать у пользователя глубоких знаний UE/Android.

## Запрос к агенту

Проведи меня через **Фазу 0 и Фазу 1** плана разработки. Вот что нужно сделать:

### Этап 0.1 — Определение версии Unreal Engine у Astroneer

1. Найди в папке с игрой (SteamLibrary\steamapps\common\Astroneer) исполняемый файл.
2. Определи версию UE4, которой собран Astroneer. Способы:
   - Свойства Astro.exe → Детали → версия файла
   - Поиск строки "UE4" в бинарнике
   - Чтение файла EngineVersion в извлечённых ассетах
3. Сообщи версию (например, 4.18, 4.22, 4.27) — это критично для выбора инструментов.

### Этап 0.2 — Установка инструментов

Составь список инструментов с прямыми ссылками и пошаговой инструкцией установки:

- **FModel** (GitHub) — для просмотра и извлечения .pak/.utoc/.ucas файлов
- **UnrealPak** (из UE4 Editor) — для распаковки/запаковки .pak
- **UE4 Editor** (Epic Games Launcher) — точная версия, совпадающая с версией движка Astroneer
- **Android NDK r25c** (или совместимая версия) — для кросс-компиляции
- **UEVR** (GitHub, praydog) — для быстрого прототипа на ПК

Дай готовые PowerShell-команды для скачивания/распаковки тулзов.

### Этап 0.3 — Извлечение ассетов Astroneer

1. Напиши команду для UnrealPak, чтобы извлечь содержимое `Astro-WindowsNoEditor.pak`.
2. После извлечения найди и покажи структуру ключевых папок:
   - Blueprints (игровая логика)
   - Textures/Materials
   - Meshes/StaticMeshes
   - Animations
   - Config (настройки движка)
3. Открой файлы конфигурации движка (DefaultEngine.ini, DefaultGame.ini, DefaultInput.ini) и покажи ключевые настройки:
   - Версию рендерера (OpenGL/Vulkan/DirectX)
   - Настройки ввода
   - Платформенные флаги

### Этап 1.0 — Прототип через UEVR

1. Скачай последнюю nightly-сборку UEVR с GitHub (praydog/UEVR).
2. Напиши пошаговую инструкцию запуска Astroneer через UEVR:
   - Запуск UEVR Injector
   - Выбор процесса Astro-Win64-Shipping.exe
   - Базовые настройки (OpenVR vs OpenXR, способ рендеринга)
3. Объясни, как протестировать на Quest 3 через AirLink/Virtual Desktop (это не standalone, но прототип).
4. Составь чеклист того, что проверить в прототипе:
   - Работает ли стерео-рендер?
   - Привязана ли камера к голове (6DOF)?
   - Есть ли артефакты теней/пост-эффектов?
   - Как ведёт себя UI?
   - Работает ли физика без привязки к фиксированной камере?

## Требования к ответу агента

- **Говори простым языком**. Объясняй термины (что такое .pak, UE4 Editor, NDK, кросс-компиляция).
- **Давай готовые команды** для PowerShell, которые можно скопировать и выполнить.
- **Проверяй пути**. Учитывай, что Steam может быть установлен на разных дисках (C:, D:, E:).
- **Предупреждай о рисках**. Если следующий шаг требует навыков, которых у начинающего нет — скажи об этом и предложи альтернативу (например: «этот шаг требует знания C++ — рекомендую изучить основы перед продолжением»).
- **Не перепрыгивай**. Не уходи в Фазу 2, пока не завершена Фаза 1. Каждый этап должен завершаться проверкой.

## Контекст для понимания сложности

Astroneer — игра на Unreal Engine 4 с процедурной генерацией планет, воксельным терраформированием и сложной физикой. Движок изначально не рассчитан на standalone VR под Android. Основные вызовы:

1. **Рендеринг**: Adreno GPU не тянет деферред-рендеринг UE4 на 90 FPS в стерео — потребуется форвард-рендеринг и агрессивная оптимизация.
2. **Терраформинг**: Воксельная система, вероятно, завязана на CPU — на ARM-процессоре может потребовать полной переработки.
3. **Память**: Quest 3 имеет ~8 ГБ ОЗУ, из которых системе доступно ~4-5 ГБ. Astroneer на ПК потребляет 6-8 ГБ.
4. **Лицензия**: Исходный код Astroneer закрыт — придётся работать на уровне бинарных патчей / инжектов, либо воссоздавать логику.

**Честное предупреждение**: полноценный standalone-порт AAA-игры силами одного начинающего разработчика — это проект, который у команды профессионалов занял бы 6-12 месяцев. Реалистичная цель на первые 3 месяца — работающий прототип с UEVR на ПК и понимание архитектуры игры.

Начинай с Фазы 0.1. Спрашивай у пользователя путь к папке с игрой, если не можешь найти её автоматически.
